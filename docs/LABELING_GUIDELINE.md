# คู่มือการติดป้ายข้อมูล (Labeling Guideline)

> ร่างเริ่มต้น — ควรให้อาจารย์ที่ปรึกษา/นักจิตวิทยาตรวจทานก่อนใช้จริง
> อ้างอิงแนวคิดจากแบบคัดกรอง 2Q / 9Q / 8Q ของกรมสุขภาพจิต

## หน่วยที่ติดป้าย
ติดป้าย **ทีละข้อความ** โดยอ่านข้อความก่อนหน้าในบทสนทนาเดียวกันประกอบ
ป้าย = ระดับความเสี่ยง *ณ จุดนั้นของบทสนทนา*

## ระดับความเสี่ยง
| ป้าย | นิยาม | ตัวอย่าง (สังเคราะห์) |
|---|---|---|
| `NORMAL` (0) | สนทนาทั่วไป, ระบายเรื่องเครียดทั่วไปที่ไม่มีสัญญาณซึมเศร้า, สำนวนเปรียบเปรย | "หิวจะตายแล้ว", "เหนื่อยหน่อยแต่สนุกดี" |
| `WARNING` (1) | สัญญาณตาม 2Q/9Q: หดหู่ เศร้า ท้อแท้ สิ้นหวัง เบื่อ ไม่มีความสุข นอนไม่หลับ รู้สึกไร้ค่า/เป็นภาระ | "รู้สึกไร้ค่า ไม่มีใครเข้าใจ" |
| `CRITICAL` (2) | ความคิด/แผน/การกระทำทำร้ายตนเองหรือฆ่าตัวตาย (ตรง/อ้อม) เช่น อยากหายไป, สั่งลา | "ไม่อยากอยู่แล้ว", "ถ้าไม่มีเราทุกคนคงสบายกว่า" |

## กฎการตัดสิน
1. ถ้าลังเลระหว่างสองระดับ → เลือก**ระดับที่สูงกว่า** (เน้น Recall)
2. ข้อความสั้นที่กำกวม (เช่น "เหนื่อย") ให้ดูบริบทก่อนหน้า ถ้าไม่มีบริบท → `WARNING`
3. การพูดถึงคนอื่น/ข่าว/เพลง ที่ไม่ใช่ความรู้สึกตนเอง → `NORMAL`
4. ประชด/มุก ที่ชัดเจนจากบริบท → `NORMAL`
5. เมื่อความเสี่ยงลดลงในข้อความถัดไป ("คุยกันแล้ว ดีขึ้นแล้ว") ให้ติดป้ายตามข้อความนั้นได้

## คุณภาพการติดป้าย
- ทั้งสองคนติดป้ายชุดเดียวกัน ≥ 200 ข้อความ → คำนวณ **Cohen's Kappa** (เป้าหมาย ≥ 0.6)
- ข้อความที่ไม่ตรงกัน → ประชุมตัดสินร่วมกัน และบันทึกเหตุผลเพิ่มลงคู่มือนี้

## รูปแบบไฟล์

```
conversation_id,turn,text,label

```
